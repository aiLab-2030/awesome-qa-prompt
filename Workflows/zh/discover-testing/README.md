# 测试 Prompt 路由 (Testing Prompt Router)

[English](../../en/discover-testing/README.md) | 简体中文

## 模块简介

根据用户目标、上下文和约束推荐应使用的测试类型 Prompt 或工作流 Prompt，并说明组合顺序。

## 文件说明

- **标准版本：** [Standard-version/DiscoverTestingPrompt.md](Standard-version/DiscoverTestingPrompt.md)
- **英文版本：** [../../en/discover-testing/Standard-version/DiscoverTestingPrompt.md](../../en/discover-testing/Standard-version/DiscoverTestingPrompt.md)

## 适用场景

- 不确定该选哪个测试类型 Prompt
- 希望把多个 Prompt 组合成一个 QA 工作步骤
- 需要根据项目阶段、输入材料和风险快速确定下一步

## 使用建议

先描述当前目标、已有材料、阶段和限制，再让本 Prompt 推荐 1-3 个最合适的入口。
