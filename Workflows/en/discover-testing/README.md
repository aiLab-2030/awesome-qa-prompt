# Testing Prompt Router

English | [简体中文](../../zh/discover-testing/README.md)

## Module Overview

Recommends the testing-type prompts or workflow prompts to use based on the user goal, context, and constraints, including order of use.

## Files

- **Standard version:** [Standard-version/DiscoverTestingPrompt.md](Standard-version/DiscoverTestingPrompt.md)
- **Chinese version:** [../../zh/discover-testing/Standard-version/DiscoverTestingPrompt.md](../../zh/discover-testing/Standard-version/DiscoverTestingPrompt.md)

## Use Cases

- You are not sure which testing-type prompt to use
- You want to combine multiple prompts into one QA workflow
- You need to choose the next step based on project phase, available inputs, and risk

## Usage Tip

Describe the current goal, available materials, project phase, and constraints first, then ask this prompt to recommend the 1-3 best entries.
